# FasTool API リファレンス

FasTool は **18 カテゴリ・265 のエクスポート**を提供します。サイドバーからカテゴリを選ぶか、以下からジャンプしてください。

- [Array](/ja/guide/Array) — 純粋な配列ヘルパー（chunk, uniq, groupBy…）
- [Objects](/ja/guide/Objects) — パス指定・ディープクローン・等価性
- [Is](/ja/guide/Is) — TypeScript の型ガード
- [String](/ja/guide/String) — 命名変換・マスキング・エスケープ
- [Number](/ja/guide/Number) — 浮動小数点安全な丸め・フォーマット・統計
- [Time](/ja/guide/Time) — フォーマットと日付計算（iOS Safari 対応）
- [URL](/ja/guide/URL) — クエリ文字列の解析と構築
- [Function](/ja/guide/Fn) — スロットル・デバウンス・合成・カリー化
- [Random](/ja/guide/Random) — 乱数と UUID
- [Storage](/ja/guide/Storage) — localStorage / sessionStorage / cookie
- [Browser](/ja/guide/Browser) — 環境とビューポートの判定
- [DOM](/ja/guide/DOM) — イベント・スタイル・クリップボード・ダウンロード
- [Device](/ja/guide/Device) — デバイスと OS の判定
- [Canvas](/ja/guide/Canvas) — 画像 ↔ Base64、色変換
- [Event](/ja/guide/Event) — 依存ゼロの mitt エミッター
- [Regex](/ja/guide/Regex) — よく使うバリデーションパターン
- [Tools](/ja/guide/Tools) — その他のヘルパー
- [Log](/ja/guide/Log) — スタイル付きコンソール出力
- [Polyfill](/ja/guide/Polyfill) — 古いブラウザ向けパッチ
- [Plugins](/ja/guide/Plugins) — CDN 経由のプラグイン

初めての方は [はじめに](/ja/guide/start) をご覧ください。
